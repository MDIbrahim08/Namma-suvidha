## Setting up PostgreSQL + PostGIS (pending)

Option A, Docker: `docker compose up -d db`.

Option B, a native install (e.g. PostgreSQL on Windows via the EDB installer, then add PostGIS with **Stack Builder**):

```sql
CREATE USER namma WITH PASSWORD 'namma_dev_password';
CREATE DATABASE namma_suvidha OWNER namma;
\c namma_suvidha
CREATE EXTENSION IF NOT EXISTS postgis;   -- needs superuser once
```

Then check that `curl http://localhost:8000/api/v1/health/db` returns `"connected": true` with a `postgis_version`.

## Running Alembic

From `backend/` with the venv active and `DATABASE_URL` set:

```bash
alembic revision --autogenerate -m "describe change"   # generate a migration from models
alembic upgrade head                                     # apply all migrations
alembic downgrade -1                                     # roll back one
alembic current                                          # show current revision
```

For autogenerate to see new models, import their modules in `alembic/env.py`.

### First migration requirement

Shubham's first migration must enable PostGIS before creating any spatial table:

```python
def upgrade() -> None:
    op.execute("CREATE EXTENSION IF NOT EXISTS postgis;")

```

Always review autogenerated migrations by hand. Autogenerate does not handle every PostGIS case (e.g. spatial indexes or `tiger`/`topology` schemas).
